# INMO Air3

**Classification:** Consumer Standalone Android  
**Price:** ~$899 pre-order / $1,099 retail  
**Maker:** INMO  
**Website:** https://inmo.cn (primary) / https://inmoglass.com  

---

## Specifications
- Fully standalone Android
- Snapdragon
- **8 GB RAM / 128 GB storage**
- Sony 0.44" micro-OLED **1920×1080**
- 36° FOV
- 600 nits
- 120 Hz
- Waveguide
- Camera
- Mics
- Speakers
- Touchpad + 3DoF ring

## Key Differentiator
**Ships internationally with real Google Mobile Services** — official Play Store deal, so app install is friction-free, no ADB needed.

## SDK
- Unity SDK + native
- Publishing mixes open Play path with a curated first-party store
- Prose API reference sits behind a login-walled Feishu doc

## Battery
- **Heavily criticised in reviews** — the killer weakness

## Recommendation
Strong hardware on paper with official Google Mobile Services. The battery life is the critical weakness that makes it unsuitable for continuous-use applications. The Feishu-walled documentation is also a concern for deep development.
